# Poovendhan R — Portfolio

Static portfolio for GitHub Pages.

## Publish
1. Create/open a GitHub repository (for example `portfolio`).
2. Upload the contents of this folder, including `assets/`.
3. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. Your site will be available through GitHub Pages.

The portfolio uses only HTML, CSS and JavaScript and does not require a build step.
